# 뽀모도로 타이머 테스트 케이스

이 문서는 실제 브라우저에서 앱을 사용하며 검증한 핵심 테스트 케이스입니다.

## 범위

- 기본 렌더링
- 설정 저장 및 입력 검증
- 목표 입력 모달
- 시작, 백그라운드 복귀 보정, 일시정지, 재시작
- 목표 문구 수정
- 스킵, 세션 히스토리 기록
- 리셋
- PWA 정적 자산 응답

## 테스트 케이스

| ID | 시나리오 | 절차 | 기대 결과 |
| --- | --- | --- | --- |
| TC-01 | 초기 화면 | 첫 접속 후 로컬 저장소를 비우고 새로고침한다. | 한국어 UI, `50:00`, 집중 50분/휴식 10분, 빈 히스토리가 보인다. |
| TC-02 | 설정 범위 검증 | 설정에서 집중 `0`, 휴식 `61`을 입력하고 저장한다. | `범위: 집중 1~180분, 휴식 1~60분` 오류가 표시된다. |
| TC-03 | 설정 저장 | 집중 `1`, 휴식 `1`, 다크 테마, 러너 진행바로 저장한다. | 타이머가 `01:00`으로 바뀌고 설정이 저장된다. |
| TC-04 | 빈 목표 방지 | 시작을 누른 뒤 목표 없이 시작한다. | 모달이 닫히지 않고 `목표를 입력해 주세요.`가 표시된다. |
| TC-05 | 목표 입력 후 시작 | 목표를 입력하고 시작한다. | 타이머가 실행되고 시작 버튼이 `일시정지`로 바뀐다. |
| TC-06 | 백그라운드 복귀 보정 | 실행 중 시간이 20초 흐른 것처럼 만든 뒤 포커스 복귀 이벤트를 발생시킨다. | 남은 시간이 실제 경과 시간만큼 즉시 줄어든다. |
| TC-07 | 일시정지/재시작 | 실행 중 일시정지 후 잠시 기다리고 다시 시작한다. | 일시정지 중 시간이 줄지 않고, 재시작 후 다시 줄어든다. |
| TC-08 | 목표 수정 | 실행 중 수정 버튼으로 목표 문구를 바꾼다. | 현재 세션 목표가 새 문구로 바뀐다. |
| TC-09 | 집중 스킵 | 집중 중 스킵을 확인한다. | 휴식 세션으로 넘어가고 세션 히스토리에 집중 기록이 추가된다. |
| TC-10 | 휴식 스킵 | 휴식 중 스킵을 확인한다. | 다음 세션 준비 상태로 이동하고 사이클이 증가한다. |
| TC-11 | 리셋 | 리셋 확인을 누른다. | 사이클 1, 현재 설정 시간의 준비 상태, 빈 히스토리로 돌아간다. |
| TC-12 | PWA 자산 | `manifest.webmanifest`, `sw.js`, 주요 아이콘 URL을 요청한다. | 모두 HTTP 200으로 응답한다. |

## 자동 스모크 테스트

아래 명령은 실행 중인 앱(`http://localhost:3000`)을 headless Chrome으로 열고 위 핵심 흐름을 자동으로 검증합니다.

```powershell
python tests/cdp_smoke.py
```

Chrome 경로를 직접 지정해야 하면:

```powershell
$env:CHROME_PATH="C:\Program Files\Google\Chrome\Application\chrome.exe"
python tests/cdp_smoke.py
```
